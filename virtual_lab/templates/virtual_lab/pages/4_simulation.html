Under the Hood: Django Stream Decoding
Standard Library Execution

This is the exact pure-Python workflow executed in virtual_lab/services/csv_parser.py to parse the file without Pandas: 

# 1. Capture in-memory uploaded stream from Django request
uploaded_file = request.FILES['csv_file']

# 2. Decode raw bytes into UTF-8 text string
decoded_text = uploaded_file.read().decode('utf-8')

# 3. Wrap in memory buffer & parse with csv.DictReader
stream = io.StringIO(decoded_text.strip())
reader = csv.DictReader(stream)
dataset = [dict(row) for row in reader]
