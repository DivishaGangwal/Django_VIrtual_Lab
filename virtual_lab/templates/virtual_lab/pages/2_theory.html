1. What is a CSV File?

A Comma-Separated Values (CSV) file is a plain-text file that stores tabular data (numbers and text) according to the RFC 4180 standard. Each line in the file represents a data record, and each record consists of one or more fields separated by a delimiter (commonly a comma ,, semicolon ;, or tab \t).

ID,Student_Name,Marks,Grade
101,Aarav Sharma,88.5,A
102,Aditi Rao,72.0,B

2. Why CSV is Universally Used
  • • Human Readable: Can be inspected in any plain text editor without specialized software.
  • • Interoperability: Supported natively by SQL databases, spreadsheets, data science pipelines, and web servers.
  • • Zero Overhead: Lightweight without proprietary binary metadata schemas.

3. How Django Handles File Uploads Internally
Django Request Lifecycle

When a browser submits a form with enctype="multipart/form-data", Django's MultiPartParser parses the incoming HTTP stream and populates the dictionary-like object request.FILES.

1. InMemoryUploadedFile (< 2.5 MB)

For files smaller than the threshold set in FILE_UPLOAD_MAX_MEMORY_SIZE (default 2.5 MB), Django holds the entire file payload in memory as an io.BytesIO stream. This enables rapid parsing with zero disk I/O latency.

2. TemporaryUploadedFile (> 2.5 MB)

For larger files, Django streams data chunks directly into a temporary file in the operating system's temp directory, preventing server memory starvation.

⚠️ Byte Stream Decoding Required
request.FILES['file'].read() returns raw bytes (e.g. b'ID,Name\n...'). Python's csv module operates on text characters. Therefore, the byte stream must be decoded via .decode('utf-8') and wrapped in an io.StringIO buffer before passing to csv.DictReader!
🐍
4. Pure Python csv Module vs Pandas
Pedagogical Comparison

While industrial data science often uses Pandas (pd.read_csv()), learning how to read CSV files with Python's built-in csv.DictReader reveals the foundational mechanics of memory buffers, string encoding, dialect sniffing, and row iterators.

External Dependencies Zero (Standard Library) Requires heavy C-extensions (NumPy, Pandas)
