Theory

The concepts behind every stage of the CSV-to-chart pipeline.

1. What is a CSV file?

A CSV file is plain text in which each line is a record and fields are separated by a delimiter — usually a comma, but semicolons (common in European locales), tabs and pipes are also used. The first line is normally a header row naming the columns.

student_marks.csv
Student_ID,Student_Name,Department,Marks
101,Aarav Sharma,Computer Science,88.5
102,"Rao, Aditi",Information Tech,72.0

Fields that contain the delimiter are wrapped in double quotes ("Rao, Aditi"). This is why splitting a line with line.split(',') is wrong — the csv module handles quoting correctly.

2. File uploads in Django

  1. The HTML form must use method="post" and enctype="multipart/form-data" (or JavaScript FormData).
  2. Django puts the file in request.FILES as an UploadedFile. Small files stay in memory; large ones are streamed to a temporary file.
  3. A forms.Form with a FileField validates it. Custom clean_<field>() methods add rules (extension, size, not-binary).
  4. CsrfViewMiddleware rejects POST requests that do not carry a valid CSRF token.

3. Decoding and parsing

Uploaded files are bytes. They must be decoded to text before parsing. Excel often adds a Byte Order Mark (BOM), so this lab tries utf-8-sig first, then cp1252, then latin-1.

services/csv_parser.py (simplified)
import csv, io

text = uploaded_file.read().decode('utf-8-sig')
delimiter = csv.Sniffer().sniff(text[:4096]).delimiter
reader = csv.reader(io.StringIO(text), delimiter=delimiter)
headers = [h.strip() for h in next(reader)]
rows = [dict(zip(headers, cells)) for cells in reader]
  • io.StringIO wraps a string so the csv module can read it like a file — no disk writes.
  • csv.Sniffer guesses the delimiter from a sample.
  • Header names are stripped of spaces, blank headers are named Column_N, and duplicates become name_2 so no column is silently lost.
  • Cells such as "", NA, null, NaN and - are counted as missing values.

4. Type inference and descriptive statistics

Every CSV value is a string. A column is treated as int or float only if every non-missing value converts to a number, as date if every value matches a date format, and otherwise as str (categorical).

In this lab Django does the grouping and aggregation (sum, mean, count, min, max) and returns {labels, datasets} JSON; Chart.js in the browser only draws it.

6. Keeping state with sessions

HTTP is stateless. After parsing, the dataset and its statistics are saved in request.session (stored in the database). The Observations page reads the same session data to build the report.
