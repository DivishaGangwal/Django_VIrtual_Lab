CSE-304 Web Engineering Lab Experiment 04 ⏱️ 45 Minutes

Reading and Visualizing CSV Data in Django

Master Django's internal file upload architecture, in-memory stream processing with Python's standard library, and client-side dynamic charting without third-party data manipulation abstractions.

🚀 Start Experiment 📖 Read Theory First

🔬 Experiment Meta

Framework: Django 6.x

Engine: Python csv + io

Visualization: Chart.js 4.4

Difficulty: Intermediate

🎯
Experiment Aim
Primary Goal

To design and implement an educational web application using the Django web framework that accepts user-uploaded CSV files, decodes raw byte streams into tabular data structures using Python's built-in csv and io modules, calculates statistical aggregations in standard Python without Pandas, and renders dynamic interactive charts in the browser via Chart.js.

📋
Learning Objectives
4 Core Outcomes
  • 01. Understand how Django captures files through request.FILES and stores them as InMemoryUploadedFile objects.
  • 02. Learn how to decode file streams with io.StringIO and extract rows using csv.DictReader.
  • 03. Implement pure Python statistical aggregation (Mean, Median, Mode, Sum, Min, Max) using standard math and statistics libraries.
  • 04. Serialize processed Python data structures into clean JSON payloads consumed by Chart.js for interactive rendering.
🛠️
Prerequisites
Knowledge Required
  • ✓ Basic Python syntax (Lists, Dictionaries, List Comprehensions)
  • ✓ Fundamentals of HTTP GET and POST request-response cycles
  • ✓ Basic understanding of HTML forms (enctype="multipart/form-data")
  • ✓ Familiarity with JavaScript Object Notation (JSON) format
🏆
Expected Outcome
Deliverables

Upon completing this laboratory experiment, students will be able to build a complete Django pipeline that takes raw tabular files from the client, validates and processes them in backend memory without third-party frameworks, and returns structured data to generate interactive Bar, Line, Pie, and Histogram visualizations.
