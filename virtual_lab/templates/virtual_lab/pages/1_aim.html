Aim of the Experiment

To build a Django web application that accepts a CSV file, parses it with Python's built-in csv module, computes descriptive statistics, and visualizes the data as interactive charts.

🎯Learning Objectives
1

Handle file uploads

Receive a file through a Django form, read it from request.FILES and validate type and size on the server.

2

Parse CSV without pandas

Decode bytes, detect the delimiter with csv.Sniffer and read rows with the csv module.

3

Infer types & compute statistics

Classify columns as int, float, date or text and compute mean, median, standard deviation and more with statistics.

4

Visualize data

Send aggregated JSON from a Django view to Chart.js and draw bar, line, pie, scatter and histogram charts.

🧰Prerequisites
  • Python basics: lists, dictionaries, loops, functions
  • Django basics: views, URLs, templates
  • What a CSV (Comma-Separated Values) file looks like
🏁Expected Outcome

By the end of this lab you will have loaded a dataset, read its statistics, produced at least two charts, generated a printable observation sheet, and completed a 10-question assessment.

💡 How to use this lab
Work through the six steps in order using the progress bar above. The Simulation (Step 4) is the hands-on part; your dataset stays loaded while you move between pages.
