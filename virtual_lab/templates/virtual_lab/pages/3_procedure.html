Procedure

Follow these steps on the Simulation page.

  1. Load a dataset. Drag a .csv file onto the upload box (max 5 MB) or pick a built-in sample and click Load Sample. Try the Lab Sensor Log sample to see missing values and a semicolon delimiter.
  2. Watch the request pipeline. The pipeline tracker lights up each stage: Browser → request.FILES → decode → csv parse → JSON response.
  3. Inspect the data. Check the detected delimiter, row and column counts, missing values (highlighted in yellow) and the inferred type tag on every column header.
  4. Read the statistics. Pick a column in the Statistics panel. Numeric columns show mean, median, min, max, standard deviation and quartiles; text columns show their most frequent values.
  5. Build charts. In the Chart Studio choose a chart type, an X column, one or more Y columns and an aggregation, then click Plot. Make at least two charts (for example a bar chart and a scatter plot) and download them as PNG.
  6. Record observations. Open the Observations page. It is generated from your loaded dataset — print it or save it as PDF, and download the statistics as CSV.
  7. Take the quiz. Answer the 10 questions. Your score is graded on the server and saved.
⚠️ Common errors you may see (on purpose)
Uploading a non-CSV file, an empty file, a file over 5 MB, or an Excel .xlsx renamed to .csv is rejected with a clear message. Try it — validation is part of the lab.
