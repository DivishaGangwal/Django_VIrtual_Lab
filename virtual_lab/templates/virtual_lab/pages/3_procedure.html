📋 Laboratory Procedure & Workflow

Follow this structured, 9-step experimental protocol to conduct the virtual laboratory simulation and complete the experiment successfully.

🧪
Experimental Execution Protocol
9 Step Procedure
1

Open the Simulation Workbench

Navigate to the interactive simulation page by clicking the "Simulation" tab in the navigation ribbon or the button at the bottom of this procedure.

2

Select or Upload a CSV Dataset

Either drag-and-drop a custom .csv file into the dropzone or choose from the three built-in educational datasets (Student Marks, Weather Telemetry, or Server Metrics).

3

Observe Django Backend File Validation

The backend automatically verifies that the uploaded file contains a valid .csv extension, is non-empty, and does not exceed the 5 MB memory threshold.

4

Inspect Django Stream Ingestion & csv.DictReader

Review the live Request-Response Pipeline Animator and the Code Inspector Card to see how io.StringIO wraps raw byte streams and converts them into Python dictionaries.

5

Preview Inferred Schema & Top Rows

Examine the auto-detected column names, data types (int, float, str), and the first 5 records in the preview table.

6

Perform Pure-Python Statistical Analysis

Select any numerical column from the dropdown to calculate Mean, Median, Mode, Min, Max, Sum, and Count computed using standard Python arithmetic and the built-in statistics module.

7

Generate and Configure Visualizations

Configure X-axis and Y-axis mappings and switch between Bar, Line, Pie, and Histogram charts powered by Chart.js.

8

Record Laboratory Observations

Navigate to the Observations page to review the auto-generated summary report, write student inferences, and print the lab sheet.

9

Complete the Post-Lab Assessment & Quiz

Answer 10 Multiple-Choice Questions to test your understanding of Django file uploads, stream decoding, and pure-Python CSV processing.
